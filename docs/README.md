## 学习路线

### 第一阶段：理解架构（第 01 篇）

- 读懂系统架构图：Web 层、Service 层、中间件层
- 理解 Dubbo 服务治理：Provider / Consumer / Registry
- 记住各模块职责与端口规划

### 第二阶段：跑起来（第 02 篇）

- 按文档搭建 MySQL、Redis、ZooKeeper、Solr、ActiveMQ、FastDFS
- 初始化数据库，导入 `Doc/taotao.sql`
- 按启动顺序依次启动 5 个 Service 与 7 个 Web 模块
- 逐页验证：后台管理 → 门户 → 搜索 → 商品详情 → 登录 → 购物车 → 下单

### 第三阶段：讲业务（第 03 篇）

- 商品管理：CRUD + 缓存 + 消息通知
- 搜索：数据导入、索引同步、查询高亮
- 购物车：Cookie 与 Redis 双存储
- 下单：订单号生成、事务、库存联动
- SSO：Token 机制、跨域登录

### 第三阶段补充：读表结构（第 06 篇）

- 通读 11 张表：商品域 / 内容域 / 用户域 / 订单域
- 理解六大设计思想：金额整数、大字段拆分、逻辑删除、快照、应用层 ID、冗余字段
- 动手完成建表练习

### 第四阶段：挖原理（第 04 篇）

- Dubbo：注册中心、负载均衡、超时重试
- Redis：缓存策略、过期、分布式 ID
- Solr：全文检索、分词、高亮
- ActiveMQ：点对点、发布订阅、异步解耦
- FastDFS：Tracker / Storage 原理

### 第五阶段：动手改（第 05 篇）

- 照着"二次开发指南"新增一个小功能（如商品评价）
- 用 FAQ 解决部署与开发中的常见问题

### 第六阶段：进阶与面试（第 07~10 篇）

- 07 面试题集锦：按五大类刷题，每题结合项目回答
- 08 分布式事务与一致性：理解 CAP/BASE，掌握本地消息表、TCC 原理
- 09 电商高级功能实战：动手实现秒杀、优惠券、收藏等进阶功能
- 10 项目答辩与简历指导：写简历、练话术、跑通演示流程

## 前置要求

- 掌握 Java 基础（集合、IO、反射、泛型）
- 掌握 MySQL 基础（建表、SQL、索引）
- 了解 HTTP、Servlet 与 JSP 基本概念
- 会用 Maven 构建项目、会用 Git 管理代码

## 项目代码结构速查

```
taotao-parent                        父 POM（统一依赖与版本）
├── taotao-common                    通用工具与 POJO（各模块共用）
├── taotao-manager                   后台管理服务（DAO/POJO/接口/实现）
├── taotao-manager-web               后台管理系统（EasyUI）
├── taotao-portal-web                门户网站（首页、导航）
├── taotao-search / taotao-search-web   搜索服务与搜索页面
├── taotao-item-web                  商品详情页（FreeMarker 静态化）
├── taotao-sso / taotao-sso-web      单点登录服务与登录页面
├── taotao-cart-web                  购物车
├── taotao-order / taotao-order-web  订单服务与订单页面
└── taotao-content                   内容管理服务（广告位等）
```
