# 02 环境搭建与项目部署

> 学习目标：从零搭建淘淘商城的开发环境，成功启动全部 12 个模块并验证联调。

## 1. 环境总览

### 1.1 需要安装的软件

| 软件 | 版本 | 用途 | 必需性 |
|------|------|------|--------|
| JDK | 1.8 | Java 运行环境 | 必需 |
| Maven | 3.6+ | 构建工具 | 必需 |
| MySQL | 5.7 | 业务数据库 | 必需 |
| Tomcat | 7/8 | Web 容器（也可用 Maven 插件） | 必需 |
| ZooKeeper | 3.4~3.5 | Dubbo 注册中心 | 必需 |
| Redis | 3.0+ | 缓存 | 必需（核心功能依赖） |
| Solr | 4.10 | 搜索索引 | 搜索功能必需 |
| ActiveMQ | 5.x | 消息队列 | 商品上架联动必需 |
| FastDFS | 5.0+ | 图片存储 | 图片上传功能必需 |

> 提示：教学环境建议使用 **Windows + VMware 里的 CentOS 7** 装中间件，或全部用 Docker 一键启动（见本文第 6 节）。

### 1.2 端口规划速查

| 端口 | 用途 | 端口 | 用途 |
|------|------|------|------|
| 3306 | MySQL | 20880~20884 | 5 个 Dubbo Service |
| 6379 | Redis | 8081 | manager-web |
| 2181 | ZooKeeper | 8082 | portal-web |
| 8983 | Solr | 8085~8091 | search/item/sso/cart/order-web |
| 61616/8161 | ActiveMQ | 22122 | FastDFS tracker |

## 2. 安装中间件（Linux 示例）

### 2.1 安装 JDK 与 Maven

```bash
# JDK 1.8（以 tar 包方式）
tar -zxvf jdk-8u202-linux-x64.tar.gz -C /usr/local/
cat >> /etc/profile <<EOF
export JAVA_HOME=/usr/local/jdk1.8.0_202
export PATH=$JAVA_HOME/bin:$PATH
EOF
source /etc/profile
java -version

# Maven 3.6
tar -zxvf apache-maven-3.6.3-bin.tar.gz -C /usr/local/
cat >> /etc/profile <<EOF
export MAVEN_HOME=/usr/local/apache-maven-3.6.3
export PATH=$MAVEN_HOME/bin:$PATH
EOF
source /etc/profile
mvn -version
```

配置阿里云镜像加速依赖下载（`~/.m2/settings.xml`）：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 2.2 安装 MySQL

```bash
# CentOS 7 使用 yum 安装 MySQL 5.7
wget https://dev.mysql.com/get/mysql57-community-release-el7-11.noarch.rpm
rpm -ivh mysql57-community-release-el7-11.noarch.rpm
yum install -y mysql-community-server

systemctl start mysqld
systemctl enable mysqld

# 查看初始密码
grep 'temporary password' /var/log/mysqld.log

# 登录并改密码
mysql -uroot -p
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Root_123456';
```

### 2.3 安装 Redis

```bash
# 需要 gcc
yum install -y gcc
wget http://download.redis.io/releases/redis-3.2.12.tar.gz
tar -zxvf redis-3.2.12.tar.gz
cd redis-3.2.12 && make && make install

# 后台启动
redis-server /usr/local/redis.conf --daemonize yes
redis-cli ping   # 输出 PONG
```

### 2.4 安装 ZooKeeper

```bash
wget https://archive.apache.org/dist/zookeeper/zookeeper-3.4.14/zookeeper-3.4.14.tar.gz
tar -zxvf zookeeper-3.4.14.tar.gz -C /usr/local/
cd /usr/local/zookeeper-3.4.14/conf
cp zoo_sample.cfg zoo.cfg

cd /usr/local/zookeeper-3.4.14/bin
./zkServer.sh start
./zkServer.sh status   # Mode: standalone
```

### 2.5 安装 Solr

```bash
wget https://archive.apache.org/dist/lucene/solr/4.10.3/solr-4.10.3.tgz
tar -zxvf solr-4.10.3.tgz -C /usr/local/
cd /usr/local/solr-4.10.3/example
java -jar start.jar &

# 创建 collection1（项目默认使用的索引库）
# 访问 http://<ip>:8983/solr/ 进入管理台
```

> 项目连接地址为 `http://<ip>:8983/solr/collection1`，需在管理台 Core Admin 中创建名为 `collection1` 的 Core，
> 并配置字段：`item_title`、`item_sell_point`、`item_price`、`item_image`、`item_category_name`、`item_desc`。

### 2.6 安装 ActiveMQ

```bash
wget https://archive.apache.org/dist/activemq/5.11.2/apache-activemq-5.11.2-bin.tar.gz
tar -zxvf apache-activemq-5.11.2-bin.tar.gz -C /usr/local/
cd /usr/local/apache-activemq-5.11.2/bin
./activemq start

# 管理台：http://<ip>:8161 （默认 admin/admin）
```

### 2.7 安装 FastDFS

```bash
# 安装依赖
yum install -y gcc libevent libevent-devel

# 安装 libfastcommon
git clone https://github.com/happyfish100/libfastcommon.git
cd libfastcommon && ./make.sh && ./make.sh install

# 安装 FastDFS
git clone https://github.com/happyfish100/fastdfs.git
cd fastdfs && ./make.sh && ./make.sh install

# 配置 tracker（/etc/fdfs/tracker.conf）
base_path=/home/fastdfs/tracker
# 配置 storage（/etc/fdfs/storage.conf）
base_path=/home/fastdfs/storage
store_path0=/home/fastdfs/storage
tracker_server=127.0.0.1:22122

# 启动
fdfs_trackerd /etc/fdfs/tracker.conf
fdfs_storaged /etc/fdfs/storage.conf
fdfs_monitor /etc/fdfs/client.conf   # 查看状态
```

## 3. 初始化项目数据库

```bash
# 创建数据库
mysql -uroot -p
CREATE DATABASE taotao CHARACTER SET utf8 COLLATE utf8_general_ci;

# 导入初始化脚本（在项目根目录执行）
mysql -uroot -p taotao < taotao.sql

# 验证核心表
mysql -uroot -p taotao -e "show tables;"
# 期望看到：tb_item、tb_item_desc、tb_item_cat、tb_content、
#           tb_order、tb_order_item、tb_order_shipping、tb_user 等
```

### 核心表说明

| 表 | 说明 | 主键 |
|----|------|------|
| tb_item | 商品基本信息 | id (Long) |
| tb_item_desc | 商品描述（富文本） | item_id |
| tb_item_cat | 商品类目树 | id |
| tb_item_param | 类目规格参数模板 | id |
| tb_item_param_item | 商品规格参数实例 | id |
| tb_content | 内容（广告位） | id |
| tb_content_category | 内容分类 | id |
| tb_user | 用户 | id |
| tb_order | 订单 | order_id (String) |
| tb_order_item | 订单商品明细 | id |
| tb_order_shipping | 订单收货信息 | order_id |

> 注意：订单表主键是 String 类型（由 Redis incr 生成），这是本项目的特色设计，讲解见第 04 篇。

## 4. 修改项目配置

### 4.1 数据源（5 个 service 模块）

文件：`taotao-*/taotao-*-service/src/main/resources/properties/db.properties`

```properties
jdbc.driver=com.mysql.jdbc.Driver
jdbc.url=jdbc:mysql://<你的MySQLIP>:3306/taotao?characterEncoding=utf-8
jdbc.username=root
jdbc.password=你的密码
```

### 4.2 Redis 地址（各 service 模块）

文件：`spring/applicationContext-jedis.xml`

```xml
<bean id="jedisPool" class="redis.clients.jedis.JedisPool">
    <constructor-arg name="host" value="<你的RedisIP>"/>
    <constructor-arg name="port" value="6379"/>
</bean>
```

### 4.3 ZooKeeper 地址（全部模块）

所有 `spring/*.xml` 与 `springmvc.xml` 中的：

```xml
<dubbo:registry protocol="zookeeper" address="zookeeper://<你的ZKIP>:2181"/>
```

### 4.4 Solr 地址（search-service）

文件：`spring/applicationContext-solr.xml`

```xml
<bean id="httpSolrServer" class="org.apache.solr.client.solrj.impl.HttpSolrServer">
    <constructor-arg name="baseURL" value="http://<你的SolrIP>:8983/solr/collection1"/>
</bean>
```

### 4.5 ActiveMQ 地址（manager/search-service）

文件：`spring/applicationContext-activemq.xml`

```xml
<bean id="targetConnectionFactory" class="org.apache.activemq.ActiveMQConnectionFactory">
    <property name="brokerURL" value="tcp://<你的MQIP>:61616"/>
</bean>
```

### 4.6 FastDFS 地址（manager-web）

文件：`src/main/resources/resource/client.conf`

```properties
tracker_server=<你的FastDFSIP>:22122
```

## 5. 编译与启动

### 5.1 编译

```bash
cd taotao-parent

# 安装父 POM
mvn install -N

# 全量编译打包（跳过测试）
mvn clean install -DskipTests
```

### 5.2 启动顺序（重要！）

**必须先启动全部 Service，再启动 Web**，否则 Web 启动时找不到 Provider。

```bash
# 终端 1~5：5 个 Service（Dubbo 端口 20880~20884）
cd taotao-manager/taotao-manager-service && mvn tomcat7:run
cd taotao-content/taotao-content-service && mvn tomcat7:run
cd taotao-search/taotao-search-service && mvn tomcat7:run
cd taotao-sso/taotao-sso-service && mvn tomcat7:run
cd taotao-order/taotao-order-service && mvn tomcat7:run

# 终端 6~12：7 个 Web
cd taotao-manager-web && mvn tomcat7:run
cd taotao-portal-web && mvn tomcat7:run
cd taotao-search-web && mvn tomcat7:run
cd taotao-item-web && mvn tomcat7:run
cd taotao-sso-web && mvn tomcat7:run
cd taotao-cart-web && mvn tomcat7:run
cd taotao-order-web && mvn tomcat7:run
```

> 小技巧：IDE 里（IDEA）可以给每个模块配一个 Tomcat Run Configuration，一键启动全部。

### 5.3 启动日志怎么看

| 日志特征 | 含义 |
|----------|------|
| `Register dubbo service ... succeeded` | Service 注册成功 |
| `Subscribe ... succeed` | Web 订阅服务成功 |
| `Connected to the target server` | ZooKeeper 连接成功 |
| `DruidDataSource ... started` | 数据源初始化成功 |
| `Tomcat started on port(s): 8081` | Web 启动完成 |

| 步骤 | 操作 | 期望结果 |
|------|------|----------|
| 1 | 访问 `http://localhost:8081` | 出现后台管理登录页 |

1. 在后台新增一个商品 → 等 2~3 秒 → 去 Solr 管理台查 `q=*:*`，看是否有新商品索引
2. 在后台新增一个商品 → 检查 item-web 的 `HTML_OUT_PATH` 下是否生成了静态页
3. 用 `redis-cli monitor` 观察访问商品详情时 Redis 是否被读写

## 8. 常见部署问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| Web 启动报 No provider | Service 未启动或 ZK 地址错 | 先启动 Service；检查注册中心地址 |
| 商品列表查不到 | MySQL 数据未导入 | 重新执行 `taotao.sql` |
| 图片上传失败 | FastDFS 未启动/配置错 | 检查 tracker_server 与进程 |
| 搜索无结果 | Solr collection 未建/字段未配 | 建 collection1 并配置字段 |
| 商品上架后搜索不到 | ActiveMQ 未启动，索引未同步 | 启动 MQ，重新导入索引 |
| 中文乱码 | 连接串缺 characterEncoding | url 加 `?characterEncoding=utf-8` |
| 端口被占用 | 上次进程未退出 | `netstat -ano \| findstr 端口` 后 kill |
