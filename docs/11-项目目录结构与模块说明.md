## 2. 根文件详解

| 文件 | 作用 |
|------|------|
| `pom.xml` | 父 POM：`<dependencyManagement>` 统一管理所有依赖版本（Spring/Dubbo/MyBatis/Redis 等）；声明 13 个 `<module>`；配置编译插件（JDK 1.7、UTF-8）；`<pluginManagement>` 统一定义 Tomcat 插件 |
| `.gitignore` | 忽略 target/、*.class、*.war、IDE 文件（.idea/.iml）、日志、临时文件等 |
| `README.md` | 项目总览：功能特性、架构图、技术栈、快速开始、端口表、配置说明、部署运维、教学文档导航 |
| `INSTALL.md` | 安装部署指南：中间件安装、数据库初始化、配置修改、启动顺序、端口表、运维指南、FAQ |
| `Docker配置.md` | 中间件 Docker 部署：MySQL/Redis/ZK/Solr/MQ/FastDFS 单容器命令 + docker-compose 编排 |
| `CHANGELOG.md` | 版本更新日志（2.0.0 / 1.0.0） |
| `CONTRIBUTING.md` | 贡献指南：Commit 规范、代码规范（JDK 1.7 兼容、禁止 System.out）、PR 流程 |
| `LICENSE` | Apache License 2.0 全文 |

## 3. 模块分类体系

淘淘商城 13 个模块分为三类：

### 3.1 公共模块（1 个）

| 模块 | 打包 | 作用 |
|------|------|------|
| taotao-common | jar | 被所有模块依赖的"工具箱"：JsonUtils（JSON 序列化）、CookieUtils（Cookie 读写）、IDUtils（ID 生成）、TaotaoResult（统一返回）、EasyUI 分页结果、SearchItem/SearchResult POJO |

### 3.2 服务聚合模块（5 个，父 POM + 子模块）

每个业务域是一个聚合模块（packaging=pom），内部再拆 interface/service（部分含 dao/pojo）：

| 聚合模块 | 子模块 | 作用 |
|----------|--------|------|
| taotao-manager | dao / pojo / interface / service | 商品核心服务（商品/类目/规格） |
| taotao-content | interface / service | 内容与广告服务 |
| taotao-search | interface / service | 搜索服务 |
| taotao-sso | interface / service | 用户与登录服务 |
| taotao-order | interface / service | 订单服务 |

**子模块分工**：

| 子模块 | 作用 | 备注 |
|--------|------|------|
| `*-dao` | MyBatis Mapper 接口 + XML + POJO 依赖 | 仅 manager 有（其他域复用其 Mapper） |
| `*-pojo` | 数据库实体（TbItem/TbUser…）+ Example | 仅 manager 有 |
| `*-interface` | Dubbo 服务接口 + 公共 POJO | 供 Web 模块依赖 |
| `*-service` | Dubbo 服务实现 + Spring 配置 | 真正执行的进程 |

### 3.3 Web 模块（7 个，war）

| 模块 | 端口 | 作用 | 主要页面/资源 |
|------|------|------|----------------|
| taotao-manager-web | 8081 | 后台管理系统（EasyUI） | item-list、content、login、jquery-easyui、kindeditor |
| taotao-portal-web | 8082 | 门户网站（首页/导航） | index、images（127张素材） |
| taotao-search-web | 8085 | 搜索结果页 | search |
| taotao-item-web | 8086 | 商品详情 + FreeMarker 静态化 | item、WEB-INF/ftl 模板 |
| taotao-sso-web | 8088 | 登录/注册页 | login、register |
| taotao-cart-web | 8089 | 购物车 | cart |
| taotao-order-web | 8091 | 订单确认/列表/后台订单 | order-cart、success、admin-order |

## 4. 标准 Maven 目录结构

所有模块遵循 Maven 标准布局：

```
taotao-xxx/
├── pom.xml                    ← 模块 POM（继承父 POM）
├── README.md                  ← 模块说明（各模块都有）
└── src/
    ├── main/
    │   ├── java/              ← Java 源码（com.taotao.xxx 包）
    │   ├── resources/         ← 配置文件
    │   └── webapp/            ← Web 资源（仅 war 模块）
    └── test/
        └── java/              ← 单元测试
```

### 4.1 src/main/java —— 代码放哪里

**Service 模块**（以 taotao-manager-service 为例）：

```
com.taotao/
├── jedis/service/impl/        ← Redis 客户端实现（JedisClientPool/Cluster）
└── service/impl/              ← 业务实现类（ItemServiceImpl 等）
```

**Web 模块**（以 taotao-manager-web 为例）：

```
com.taotao/
├── controller/                ← Spring MVC 控制器
├── exception/                 ← 全局异常处理器
└── utils/                     ← 模块内工具（FastDFSClient）
```

### 4.2 src/main/resources —— 配置放哪里

**Web 模块**（两个子目录）：

| 目录 | 内容 |
|------|------|
| `resources/resource/` | 业务配置（resource.properties：CART_KEY、TOKEN_KEY、IMAGE_SERVER_URL 等） |
| `resources/spring/` | Spring MVC 配置（springmvc.xml：组件扫描、视图解析、Dubbo 引用） |

**Service 模块**（三个子目录）：

| 目录 | 内容 |
|------|------|
| `resources/properties/` | db.properties（数据源）、resource.properties（业务配置） |
| `resources/spring/` | Spring 配置：applicationContext-dao/service/trans/jedis/activemq 等 |
| `resources/mybatis/` | SqlMapConfig.xml（MyBatis 全局配置） |

### 4.3 src/main/webapp —— 页面放哪里（war 模块）

| 目录 | 内容 |
|------|------|
| `WEB-INF/jsp/` | JSP 页面（含 error/exception.jsp 错误页） |
| `WEB-INF/web.xml` | Servlet 配置（过滤器、DispatcherServlet） |
| `css/` `js/` `images/` | 静态资源（不同模块侧重不同） |
| `WEB-INF/ftl/` | FreeMarker 模板（仅 item-web，页面静态化用） |

### 4.4 src/test —— 测试放哪里

| 测试文件 | 位置 | 测试对象 |
|----------|------|----------|
| ContentCategoryServiceImplTest | content-service | 内容分类删除逻辑（Mockito） |
| OrderServiceImplTest | order-service | 订单创建逻辑（Mockito） |
| SearchServiceImplTest | search-service | 搜索分页计算（Mockito） |
| SpringActivemq / TestActiveMq | manager-service | ActiveMQ 连接演示（教学示例） |

## 7. 依赖关系图

```
taotao-manager-web ──┐
taotao-portal-web ──┤
taotao-cart-web  ───┼──► taotao-manager-interface ──► taotao-manager-service ──┐
taotao-item-web  ───┤                                                     ├──► taotao-common
taotao-search-web ──┼──► taotao-search-interface ──► taotao-search-service ──┘
taotao-sso-web    ──┼──► taotao-sso-interface ──► taotao-sso-service
taotao-order-web  ──┴──► taotao-order-interface ──► taotao-order-service
taotao-manager-web ──► taotao-content-interface ──► taotao-content-service
taotao-portal-web ──► taotao-content-interface
```

要点：
- **所有模块都依赖 taotao-common**（公共工具）
- **Web 模块只依赖 interface**（Dubbo 远程调用，不依赖实现）
- **service 模块依赖 dao/pojo + interface**（本地实现）
- **其他域的 service 复用 manager-dao 的 Mapper**（订单/用户表 Mapper 在 manager-dao）
